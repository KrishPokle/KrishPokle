This is the first post on my new site. I built it from scratch with plain HTML, CSS and JavaScript. There's no framework and no build step, just files a browser can open.

How it's put together

Everything about me (bio, projects, resume) lives in one file, js/content.js. Each page has empty slots, and a small script fills them in from that file. Updating my info means editing one file instead of five.

The site also has five themes. Try the switcher at the top of the page:

  • Pokémon turns the site into a Pokédex entry, with pixel headings and game text boxes.
  • Lavender is soft and calm, with rounded serif headings.
  • Paper is clean and quiet.
  • Terminal is dark, monospaced and a little nerdy.
  • Pop has loud colors and chunky outlines.

Each theme is just a set of CSS variables. Picking a theme changes one attribute on the page, and every color and font follows:

[data-theme="pop"] {
  --bg: #F1EBFF;
  --ink: #1E1240;
  --accent: #FF4F8B;
}
